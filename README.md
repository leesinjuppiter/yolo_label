# 煤流异物与邻域物料标注

以 4911 原始标注为起点，在原图上复核异物 OBB、比较两种邻域并补标物料。工作台使用本机 Conda 的 `torch_env`，无需加载模型。默认读取桌面的 `new_dataset`，复核结果和历史保存在本项目的 `.local/reviews.sqlite3`。

## 启动

在项目目录用 PowerShell 运行以下命令，随后打开 [本机标注工作台](http://127.0.0.1:5188/)。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

可选参数 `-DatasetPath` 指定含 `sample_manifest.csv` 的数据目录，`-DataDir` 指定复核数据库目录，`-Port` 指定本机端口。使用 `Ctrl+C` 停止。重新启动时使用同一数据目录可接续标注。

## 首批试标

1. 在首批 100 张中逐帧检查整图异物。已有框作为预标注。修正旧框、补齐遗漏的异物；确认整帧无异物时勾选对应状态并保存。
2. 在阳性图中切换 `0.5L`、`1L` 或同时显示。L 取各个当前异物框的长边，距离取物料中心到异物旋转框的最近距离，在框内时取零。多个异物邻域重叠时，物料只计一次。两个范围之间的物料可以单独显示。
3. 记录邻域判断与原因。复核全图异物和 1L 内的物料后勾选对应完成状态。切换显示范围时可以继续沿用已编辑的物料框。首批试标与 600 张训练批次使用同一份样本记录。
4. 用结果筛选回看争议图。逐图判断用于评估范围，导出时由你为整个批次选择统一倍数。

页面每 10 秒检查一次当前图，有未保存的修改时自动保存。拖动画框时会暂缓保存，也可以随时点击「保存」。

右侧「画布中的标注」可逐框显示或隐藏，便于处理重叠框。显示状态作用于当前图的画布预览。鼠标移到已选框内部时会显示四向移动光标，可以拖动该框。

## 成对导出

右上角的 A/B 导出包含当前全部符合复核条件的样本。两包共享样本清单、数据集合及异物框。A 只含 `0 foreign`，B 增加选定范围内的 `1 surrounding_material`，确认无异物的样本在 A、B 中均生成空标签。原始贴边框以原始几何计算邻域，导出时将角点限制在图像范围内。若裁边后无法形成有效区域，服务会指出需要修正的样本与框。

ZIP 内的 `review/` 记录导出范围、样本批次、子类和复核版本。仅完成试标时，导出主要用于检查标签结构和成对一致性。开始训练前应备齐复核完成的训练及独立验证样本。
