# B600 与 B1189 双类别对照

B600 通过 B1189 快照和 A600 val_v3 的样本清单生成。两档均逐图校验与对应 A 组的图像和异物框，冻结共同验证集。

分类编号为 0 foreign 和 1 surrounding_material。原始预测阈值 0.001，NMS IoU 0.70，评价使用旋转多边形 IoU 0.50。分别给各模型校准异物阈值，主档允许最多 1/191 张阴性图误报，同时报告 0、2 张误报档。物料阈值 0.25 用于探索，在相同异物阈值下评估真值邻域和实际预测邻域。

B600 对比原生最佳权重。B1189 同时对比原生最佳权重与按召回选择的检查点。正式物料评估依赖验证集标注复核。独立测试依赖固定工作阈值及已复核的测试标签。

在服务器工作区解包此仓库并运行 experiments/yolo26_obb_b_series/queue.sh。服务器输入路径以既有 A600、A1189 训练目录为准。
