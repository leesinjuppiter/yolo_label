# A779 4911 异物检测训练

训练使用 600 张 4911 首档图与 179 张人工复核的 LSW 图。固定验证集为与 A600 重评相同的 `val_v2`，共 300 张，含 113 个异物和 191 张确认阴性。训练标签统一为 `foreign`。

默认在 `~/autodl-tmp/yolo_obb_1122` 查找 `4911_A779_foreign_YOLO_OBB_val_v2.zip`，环境为 Python 3.12、Ultralytics 8.4.115、PyTorch 2.8.0+cu128。使用官方 `yolo26n-obb.pt` 通用预训练权重，以 ZIP 和权重的 SHA-256 校验版本。

```bash
bash run.sh probe
bash run.sh train 24
```

测速比较 batch 24 与 28 的第二轮吞吐与显存。正式训练选择能稳定通过训练和验证的较快批大小，从通用权重独立启动。模型、预训练权重、输入 960、随机种子 26、优化器和增强沿用 A600。预算 100 轮，早停耐心 20 轮。启用 AMP、RAM 图像缓存和 8 个加载 worker。训练期间以 1 秒间隔记录 GPU 负载。

正式训练结束后自动用 `best.pt` 对 `val_v2` 跑一对多 + NMS。按旋转框多边形 IoU ≥0.50 一对一匹配，报告允许 0、1、2 张阴性误报时的异物检出数。A600 在允许 1 张阴性误报时为 94/113，A779 在同一误报预算下比较。预测和阈值保存在 `val_eval/`。
