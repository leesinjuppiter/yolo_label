# YOLO26-OBB 四尺度与四训练集对照

顺序为 A600、B600、A1189、B1189，每个数据集依次训练 s、m、l、x。统一官方预训练、960 输入、种子 26、训练上限 100 轮及耐心 20 轮。2026-11-24 起，对尚未开始的组先用 B1189 中标注最密集的子集做真实前向、反向和验证。候选 batch 须完成试跑，且显存峰值不超过 10,752 MiB。同尺度复用验证过的值。续训沿用已有检查点的设置。运行配置、显卡采样和异常均可从日志追溯。

训练前逐文件核验四套冻结数据及独立测试集 T724。固定验证集 val_v3 的异物误报档为 0、1、2，主档为最多 1/191 张阴性误报。原生最佳、末轮及定期权重在验证集上一并比较，先按主档召回挑选。将权重及阈值原子写入 threshold_lock.json 后推理 T724。B 模型在验证和测试时均取 foreign 类。测试报告使用旋转四边形 IoU，输出异物召回、精确率、纯煤流误报、外部 AP50 / AP50–95 及原始推理延迟。

服务器入口 experiments/yolo26_obb_matrix/queue.sh。服务器结果位于 obb_matrix_20261123 目录，summary.csv 和 summary.json 每组测试通过后更新。
