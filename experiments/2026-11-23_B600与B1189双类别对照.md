# B600 与 B1189 双类别对照

以官方 YOLO26n-OBB 权重训练 B600 和 B1189。B600 从 B1189 选择 A600 的 600 张训练图。服务器逐图校验每档 A/B 的图片、样本 ID 与异物框。B600 的训练标签包含 269 个异物及 4263 个物料框，B1189 包含 520 个异物及 8330 个物料框。固定验证集含 300 张图、113 个异物及 1685 个物料框。

960 像素输入，一对多头和按类 NMS 0.70。以旋转多边形 IoU ≥ 0.50 按类匹配。每个模型分别定异物阈值，主档允许 191 张纯煤流阴性图中最多一张误报。B600 复用 A600 的 8 个加载进程及原生最佳权重对照。B1189 复用 A1189 官方组的 12 个加载进程与定期保存权重的规则。两档均为 batch 24、seed 26、AMP 和 RAM 缓存。
