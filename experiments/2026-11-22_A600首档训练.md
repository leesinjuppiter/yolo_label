# A600首档训练

| 数据 | 图片数 | 阳性 / 阴性 | 异物框 | 说明 |
|---|---:|---:|---:|---|
| A600 首档训练 | 600 | 254 / 346 | 270 | 2 个采集组。试标 100 张已计入首档 |
| 固定验证 v1 | 300 | 106 / 194 | 110 | 首次训练与推理对照使用的标签 |
| 固定验证 v2 | 300 | 109 / 191 | 113 | 保留固定的 300 张图，补标 3 个异物 |

A600 训练类别为 `foreign`，确认阴性采用空标签。270 个训练异物框中，锚杆 130 个、网片 115 个、板状物 11 个、木条 9 个、瓶子 3 个、瓶盖类 1 个、未细分异物 1 个。

| 项目 | 实际设置或结果 |
|---|---|
| 初始化 | Ultralytics 官方通用预训练权重 `yolo26n-obb.pt` |
| 环境 | Python 3.12.3，Ultralytics 8.4.115，PyTorch 2.8.0+cu128，CUDA 12.8 |
| 训练配置 | imgsz=960，batch=24，workers=8，AMP 开启，RAM 缓存，seed=26 |
| 优化 | AdamW，lr0=0.001，余弦学习率，weight_decay=0.0005，mosaic=0.5，最后 10 轮关闭 Mosaic |
| 训练进度 | 预算 100 轮，patience=20，第 97 轮早停，最佳轮次第 77 轮 |
| 原生指标（v1，`best.pt`） | mAP50 约 81.3%，mAP50–95 约 55.3% |
| 批大小测速 | batch 24：114.6 张/秒，峰值显存 9,478 MiB。batch 40：97.0 张/秒，峰值显存 11,894 MiB。取第二轮训练吞吐 |
| 正式运行 GPU 采样 | 1 秒间隔，777 次采样的 GPU 利用率中位数 71%，峰值显存 9,516 MiB |

代码归档于 GitHub 独立实验分支，训练运行对应提交 `a54668a`。[A600 训练代码](https://github.com/leesinjuppiter/yolo_label/tree/a54668a80c13eae5740719ba9cff5b6dc4cd2875/experiments/yolo26_obb_a600)
