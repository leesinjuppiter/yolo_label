# A600推理头与分辨率对照

下表使用同一份 A600 `best.pt` 和验证 v1。每种配置在同一阴性误报预算下选取各自的阈值。数字为匹配上的异物实例数。

| 阴性误报预算 | 一对一，960 | 一对多 + NMS，960 | 一对一，1280 |
|---|---:|---:|---:|
| 0 / 194 | 41 / 110 | 74 / 110 | 25 / 110 |
| 1 / 194 | 71 / 110 | 81 / 110 | 29 / 110 |
| 2 / 194 | 73 / 110 | 87 / 110 | 61 / 110 |

选择 **960 + 一对多 + NMS** 用于后续对照。云端 Ultralytics 8.4.115 的推理参数为 `end2end=False`，NMS IoU=0.70。预测以置信度 0.001 为存档下限，随后按各误报预算计算阈值。NMS IoU 与评价匹配 IoU 分别使用 0.70 和 0.50。



固定验证标签修订后的结果见 [A600 固定验证集 v2 重评](./2026-11-22_A600固定验证集v2重评.md)。
